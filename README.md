# 📰 Projeto Escolar - IFPI Campus Parnaíba (2025)

Este é um projeto escolar desenvolvido no Instituto Federal do Piauí (IFPI), Campus Parnaíba, durante o ano de 2025. O objetivo principal é a criação de um **jornal estudantil**, voltado para:

- Apresentar notícias relevantes entre os estudantes da instituição
- Compartilhar tendências, ideias e iniciativas estudantis
- Divulgar acontecimentos internos do campus
